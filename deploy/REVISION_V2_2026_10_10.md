# Sadam Gadget V2 — Revisi Registrasi, UX, Branding, Analitik (2026-10-10)

## Diterapkan pada branch `feature/v2-pos-mobile-analytics`

1. Pendaftaran pelanggan baru menggunakan kode OTP email 6 digit, kedaluwarsa 10 menit, maks. 5 percobaan, kirim ulang minimal 60 detik. Akun baru harus verifikasi sebelum login. Akun lama tetap kompatibel.
2. Reset password melalui kode email SMTP; mengganti password mencabut sesi login sebelumnya melalui `token_version`.
3. Alamat pengiriman memakai dropdown provinsi → kab/kota → kecamatan → desa/kelurahan dan kode pos otomatis (jika data tersedia). Data disediakan oleh https://www.emsifa.com/api-wilayah-indonesia/v2. Perlu koneksi internet, dan data wilayah bergantung ketersediaan penyedia.
4. Tombol chat WhatsApp diringkas menjadi bubble yang bisa dipindahkan dengan drag dan posisi disimpan di browser. Tidak muncul di halaman admin.
5. Pengaturan Admin → Identitas Toko: upload logo dan foto hero menggunakan upload image API yang sudah ada; edit judul, deskripsi, dan foto. Logo digunakan di header toko, admin, login dan ikon tab.
6. Analitik User menampilkan total pengguna, pelanggan, staf/admin, verifikasi dan pendaftaran 7/30 hari. Owner/Admin dapat mengunduh CSV tanpa password/token.
7. Tombol download CSV laporan memakai Axios terautentikasi + Blob, bukan `window.open`, sehingga cocok untuk bearer token dan browser mobile.

## API baru
- POST `/api/auth/verify-email`
- POST `/api/auth/resend-verification`
- POST `/api/auth/forgot-password`
- POST `/api/auth/reset-password`
- GET `/api/admin/users/summary` (Owner/Admin)
- GET `/api/admin/users/export` (Owner/Admin)

## Persiapan environment (jangan kirim kredensial ke chat)
File `backend/.env` wajib mengandung `JWT_SECRET`, `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `EMAIL_FROM`, `OWNER_EMAIL` dan pengaturan lama yang dibutuhkan.
SMTP port 465 (TLS langsung) atau 587 (STARTTLS).

## Uji secara manual sebelum dipakai transaksi nyata

- Register email baru → masuk ke halaman verifikasi → pastikan email OTP diterima → kode salah ditolak → kode benar diterima → login berhasil; belum verifikasi tidak bisa login.
- Logout → lupa password → terima kode reset → set password baru → login lama tidak berlaku.
- Menu Akun → Tambah Alamat → pilih provinsi/kota/kecamatan/desa → periksa kode pos dan simpan/edit.
- Menu admin → Pengaturan → upload logo/banner → Simpan → cek di toko, login, tab, dan beranda.
- Chat WhatsApp: drag bubble di HP; muat ulang halaman; pastikan posisi tetap dan tombol tetap bisa diklik.
- Owner/Admin → Analitik User → unduh CSV → buka di Excel; jangan tampilkan hash password atau token.
- Owner/Admin → Laporan → unduh ketiga CSV → buka dari Android dan Excel.
