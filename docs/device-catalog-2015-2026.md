# Master Brand dan Model Smartphone (2015–20 Oktober 2026)

> **Status:** katalog awal/seed untuk dropdown Sadam Gadget, **belum katalog global yang lengkap**. Memuat model pilihan lintas tahun 2015–2026. Tidak semua model tersedia resmi di Indonesia; sebagian seri impor/bekas. Verifikasi model/region ketika menerima unit. Brand **Apple adalah default**, selain itu diurutkan alfabetis. ## Catatan integrasi aplikasi

- Dropdown **Merek**: Apple pertama dan terpilih secara default, merek lain berdasarkan A–Z. Hindari menempatkan 'iPhone' sebagai merek; mereknya Apple.
- Dropdown **Model**: hanya model dari merek pilihan, tersedia pencarian teks dan pilihan 'Tambah model baru'.
- **Varian / storage**: jangan menciptakan opsi yang belum diverifikasi. Bentuk master data tersendiri, bisa ditambah admin dan disimpan permanen.
- **Alias**: normalisasi pencarian (misal 'Iphone' → Apple iPhone, 'Samsung S24' → Samsung Galaxy S24); jangan otomatis menebak model hanya dari teks buram.
- **Pembaruan berkala**: daftar awal ini bukan daftar final seluruh SKU dunia. Tambahkan validasi sumber resmi ketika import, dan dokumentasikan asal/region untuk model yang kurang pasti.
- **Tanpa perubahan produksi**: file ini hanya dokumentasi dan seed yang harus diperiksa sebelum diimpor; tidak ada migrasi DB, perubahan aplikasi, atau deploy otomatis.
